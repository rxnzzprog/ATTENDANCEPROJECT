# QR Code Attendance Management System

A web-based **QR Code Attendance Management System** built with **Node.js, Express, MySQL, HTML5, CSS3, and JavaScript**.

Designed for college projects with three distinct user roles: **ADMIN**, **TEACHER**, and **STUDENT**.

---

## 🌟 Key Features

### 👑 ADMIN
* System Dashboard with real-time statistics (total students, teachers, subjects, attendance rate).
* Complete CRUD management for **Student accounts**, **Teacher accounts**, **Courses**, **Sections**, **Subjects**, and **Student Enrollments**.
* Access system-wide attendance reports with CSV export and PDF printing support.

### 👨‍🏫 TEACHER
* View assigned subjects and class sections.
* Launch live **Attendance Sessions** with dynamic QR Code generation and real-time expiration countdown timer.
* View live student scan list updating automatically via real-time polling.
* **Manual Attendance Control**: Manually mark or edit student status (Present, Late, Absent).
* View session history and generate class attendance reports.

### 🎓 STUDENT
* Personal dashboard displaying enrolled subjects and calculated attendance percentages.
* **Mobile-Friendly QR Scanner**: Scan dynamic QR codes using device camera (or enter manual session token).
* **Anti-Duplication Guard**: Prevents duplicate scans for the same class session.
* Complete attendance log history (Date, Time, Subject, Teacher, Status, Remarks).

---

## 🗄️ Database Architecture

The system uses 9 core tables specified in `schema.sql`:
1. `users` — User credentials and role assignments (`admin`, `teacher`, `student`).
2. `courses` — Academic degree programs (e.g. BSCS, BSIT).
3. `sections` — Class sections (e.g. BSCS-3A, BSIT-2B).
4. `students` — Student profile records linked to users.
5. `teachers` — Faculty profile records linked to users.
6. `subjects` — Academic subjects assigned to teachers.
7. `enrollments` — Maps students to subjects and sections.
8. `attendance_sessions` — Temporary QR session tokens generated by teachers.
9. `attendance_records` — Individual attendance scan logs with status (`Present`, `Late`, `Absent`).

## 🚀 How to Run the Application

### 1. Requirements
* **Node.js** (v18 or newer)
* **MySQL / MariaDB** (Optional; if MySQL is not running, the system automatically runs on SQLite fallback!)

### 2. Start the Server
Open terminal in the project directory and run:

```bash
node src/app.js
```

Then open your browser and navigate to:
👉 **`http://localhost:3000`**

## 🔒 Security Best Practices Implemented
* Passwords hashed using `bcrypt` (10 rounds).
* Session authentication powered by **JWT (JSON Web Tokens)** stored in HttpOnly cookies or Bearer headers.
* Role-based authorization middleware (`requireRole('admin')`, `requireRole('teacher')`, `requireRole('student')`).
* All database queries use **parameterized SQL queries** to eliminate SQL Injection risks.
